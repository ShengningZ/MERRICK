# Security policy

Please do not file public issues for vulnerabilities involving MERRICK pairing,
desktop control, credential handling or private user data. Use the MERRICK
repository's **Security → Report a vulnerability** flow so reports and
supporting material remain private while they are investigated:

https://github.com/ShengningZ/MERRICK/security/advisories/new

Include the affected plugin version, a minimal reproduction, the observed
impact, and the macOS, MERRICK and OpenClaw versions involved. Do not include
real API keys, voiceprints, private memory or other personal data.
