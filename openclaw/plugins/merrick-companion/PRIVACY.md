# Privacy

The 0.1.0 status tool contacts only `http://127.0.0.1` on the same Mac. It does
not collect telemetry, transmit user content, read files, capture screens, or
send requests to MERRICK's cloud providers. The plugin package contains no
MERRICK memories, API keys, OAuth credentials, voiceprints or model assets.

Future native actions will require a separately documented local pairing and
audit design before publication.
